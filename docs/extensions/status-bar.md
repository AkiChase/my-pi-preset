# Status Bar：统一状态栏

将 Pi 底部信息集中为三行，查看位置、上下文用量和费用。仅在交互式 TUI 中显示，加载后默认启用。

## 使用

输入 `/statusbar`，切换统一状态栏与内置 footer；再次输入即可切回。没有独立快捷键或 `on`、`off` 子命令。开关不写配置，扩展重新加载后默认启用。

## 第一行：位置

显示当前目录、Git 分支、文件状态及已有会话标题。

| 标记 | 含义 |
| --- | --- |
| `~` | 工作区中有修改的文件数 |
| `+` | 已暂存的文件数 |
| `?` | 未跟踪的文件数 |
| `✖` | 冲突文件数 |
| `↑` / `↓` | 相对上游领先／落后的提交数 |
| `✓` | 没有上述变化 |
| `⌀` | detached HEAD |

非 Git 目录或 Git 不可用时不显示 Git 信息。信息约每三秒随界面刷新更新，可能稍有延迟。

## 第二行：上下文与模型

显示上下文百分比、已用 token／窗口容量及当前模型。超过 70% 显示警告色，超过 85% 显示错误色。`(auto)` 表示 Pi 的自动压缩已启用；压缩后用量暂未知时显示 `?`，等待后续响应更新。多个 provider 可用时显示 provider，支持推理的模型显示思考等级。

## 第三行：用量与扩展状态

`↑` / `↓` 为累计输入／输出，`R` / `W` 为缓存读取／写入。`H` 是最近一次助手请求的缓存命中率，`$` 是已记录的累计费用。费用依赖模型返回的用量与计价信息，不是账单核对工具。首次响应前显示占位符，没有数值的字段可能不显示。

安装 [pi-cache-optimizer](../packages/cache-optimizer.md) 后，可显示 `⛁` 累计缓存比例与 token 对；`⛁ off` 表示缓存优化关闭，`⚠` 表示兼容性提示。任务摘要及其他扩展发布的底栏状态也会显示。

## 配置与限制

无专用配置文件或环境变量，自动压缩标记跟随 Pi 设置。终端宽度不足时会截断信息。其他扩展若也替换 footer，后启用的 footer 会覆盖前一个。
