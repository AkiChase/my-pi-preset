# Memory：项目记忆

Memory 让助手把值得跨会话保留的东西记在项目里：你的偏好、被纠正过的做法、项目本身的硬性约束，以及外部资料的地址。每次会话开始时，助手会看到一份简短索引；需要细节时再按名字读取正文。

它只保存你或助手主动写下的内容，不会在后台总结对话，不写日志，也不会在建索引时调用模型。记忆里存的是写下当时的观察，涉及文件、行为或状态时仍要重新核对。

## 工具

这些是助手调用的工具，不是斜杠命令。

| 工具 | 用途 |
| --- | --- |
| `memory_write` | 新建或更新一条记忆。更新要先读取，并带上刚拿到的版本号。 |
| `memory_read` | 按名字读取一条记忆的正文和版本号。 |
| `memory_list` | 按关键词分页浏览，只匹配名字和说明。 |
| `memory_forget` | 按名字和版本号明确删除，不生成备份。 |

直接说“记住我们在本仓库用 pnpm”就会触发保存；助手也会在你纠正它、或发现项目里有非显而易见的规定时主动记下来。不值得记的东西（代码里能看出来的、Git 历史、每天的流水、任务状态、密钥）会被跳过。

删除是不可恢复的：没有回收站，也没有备份。删除只能让助手用 `memory_forget` 完成，可以先在面板里看清楚内容。

## 查看

```text
/memory         在 TUI 中打开面板（只读）
/memory list    列出记忆摘要（只显示前 20 条）
/memory list <关键词>
/memory on      开启记忆
/memory off     关闭记忆
/memory help    用法说明
```

面板是只读的：能看到每条记忆的类型、名字、说明和正文，但不能在里面改动。增删改都通过工具完成。面板里的按键：

| 页面 | 按键 | 作用 |
| --- | --- | --- |
| 列表 | `↑` `↓` `Home` `End` | 移动选择 |
| 列表 | `Enter` | 查看所选记忆 |
| 列表 | `/` | 就地过滤名字和说明；`Enter` 或 `Esc` 结束输入 |
| 列表 | `c` | 清除过滤 |
| 列表 | `r` | 重新读取磁盘内容 |
| 列表 | `Esc` | 关闭面板 |
| 详情 | `↑` `↓` `Home` `End` | 滚动正文 |
| 详情 | `Esc` 或 `←` | 返回列表 |
| 详情 | `r` | 重新读取 |

Pi 全屏模式下可用鼠标滚轮滚动正文，在标题栏或底栏滚动不会影响面板后面的对话。

`/memory off` 之后，面板里的记忆仍然可以查看，但不会再被注入，写入也会被拒绝。已经进入当前对话内容的记忆不会被撤回。

## 存储与限制

默认放在 `~/.pi/agent/memory/projects/<项目>/`，跟随 `PI_CODING_AGENT_DIR`。每个项目一个目录：Git 仓库按它在本机的实际位置识别，同一仓库的子目录和 worktree 共用一份记忆；不在 Git 仓库里的目录各自独立。目录下每条记忆是一个 `.md` 文件，加上一份由这些文件派生出来的 `MEMORY.md` 索引。索引可以随时重建，手改正文刷新后就能看到。

| 限制 | 数值 |
| --- | --- |
| 单条记忆 | 16 KiB 以内 |
| 注入的索引 | 最多 200 行（含标题，约 197 条）、25,000 字节 |
| `memory_list` 每页 | 默认 20 条，最多 50 条、8 KiB |
| 说明文字 | 160 个字符以内 |
| 名字 | 小写 ASCII slug，80 字符以内 |
| 一次扫描 | 最多 2,000 个条目、2 MiB 元数据 |

超过单个记忆上限的写入会被拒绝，提示你缩短正文。外部改大的文件超过上限时，面板只显示有界预览，并明确标注内容被截断、没有完整版本号，也不能在面板里改回；请自行修复文件。

目录项或元数据总量超过上限时，Memory 会拒绝写入并提示手工清理，而不会自动丢弃旧记忆。

同名文件、版本号不符、文件权限异常、路径里出现符号链接等情况都会报错，而不是静默覆盖。密钥和私钥这类内容会被拒绝保存，提示命中的规则名，但不会显示命中的内容；这只是常见模式的检查，不保证识别全部敏感信息。

同一个项目被多个会话同时写入时，会短暂加锁；外部工具绕开锁直接改文件的情况无法完全避免，Memory 只能检测并缩小冲突窗口。少数情况正文已保存但索引需要修复，此时会明确提示，下次刷新可重建。

## 配置

配置文件是 agent 根目录的 `memory.json`，默认 `~/.pi/agent/memory.json`，目前只有一项：

```json
{
  "enabled": true
}
```

`/memory on` 和 `/memory off` 会写这个文件，也可以手工修改，下一轮对话即生效。如果写入后无法确认落盘，命令会如实说明磁盘上的实际状态。

## 从 pi-memory 迁移

本预设以前安装外部的 `pi-memory` 包。现在 Memory 是内置的，预设的 `conflicts` 里列出了 `npm:pi-memory`，同步时会把它移除。

内置 Memory 与旧插件的文件格式不同，但共用 `~/.pi/agent/memory/` 这个目录：内置实现只用自己的 `projects/` 子目录，旧插件的 `MEMORY.md`、`SCRATCHPAD.md`、`daily/`、`recovery/` 不会被转换，也不会被自动删除，两者互不干扰。需要保留的内容请自行复制，然后按 [README](../../README.md) 的同步与更新一节执行同步并重启。
