# Widget Display：内置信息统一展示

Widget Display 为预设内置插件提供编辑器区域的信息展示。它随预设加载，没有额外命令或个人配置。

编辑器上方的内置信息按固定顺序排列：Recap 在 Trellis 任务信息之前；未显示的内容不占位。编辑器下方展示只读 Agent／workflow 根任务概览，最多五项；小终端会减少行数并提示隐藏数量。极端拥挤时 Pi 仍可能裁剪概览或底栏，隐藏数量不保证始终可见。内容更新不会改变内置信息之间的顺序。

这个排序不控制未接入的第三方插件。第三方 widget 与整个内置展示区域之间的位置仍由 Pi 决定。状态栏、任务面板和 Memory 浏览器使用各自的展示入口，不属于此区域。

使用 Recap、Trellis 和 Task Composition 时，请保持 Widget Display 入口启用。单独加载这些插件而不加载共享展示入口时，相关 widget 无法显示；命令、任务执行等非展示能力不由它管理。
