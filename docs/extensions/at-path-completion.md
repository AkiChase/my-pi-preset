# At Path Completion：路径连续补全

在输入框用 `@` 引用文件时，这个扩展让目录补全可以接着往下选，不必每进入一层都再按一次 Tab。候选仍是 Pi 原来的列表。

## 怎么用

例如输入 `@./`，或在 `@src` 后手动输入 `/`。出现候选后，用原生的 Tab、Enter 或列表点击接受目录，随后会提示新一轮候选。

常用路径写法包括：

```text
@local/
@./
@../
@~/
@/绝对路径/
@"带空格目录/"
```

新一轮即使只有一个子项，也只是显示出来，不会替你接受。选中目录时按 Enter 不会提交消息；选中文件仍沿用原生的文件补全行为，填入后补尾随空格。空目录没有候选时，列表保持关闭。

按 Escape 关闭列表后，不会仅因为路径还以 `/` 结尾就再次弹出。正文里的 `/`、斜杠命令、电子邮件和普通 agent handle 不会因为这个扩展额外打开目录列表，整段粘贴也不触发额外的目录续提示。

## 保留的原生行为

文件搜索、候选排序、忽略规则和列表操作仍由 Pi 提供。它不会把搜索换成严格的单层目录浏览；原生搜索可能包含更深层的匹配项。历史导航、撤销和光标操作照常使用。

本扩展没有配置文件、斜杠命令或新快捷键，也不依赖 Beautify 或任务面板；可以单独加载。

如果换了编辑器或升级 Pi 后增强不可用，加载日志会提示保留原生 Tab 补全。此时可以继续按 Tab 补全，不必依赖自动续提示。切换焦点、后续编辑或关闭会话后，待续提示会取消，不会应用到新内容。
