# Tool Guidance：可选参数调用提示

在默认 system prompt 的 `<rules>` 中添加一条通用说明：未使用的可选参数应省略，不用空字符串或 `null` 占位；字段明确支持空值或实际 schema 要求 nullable 时除外，保留有效的 `false` 和 `0`。

说明只出现一次，与工具使用规则放在一起。扩展没有命令、快捷键或配置，不注册工具，也不修改工具参数或执行行为。

自定义或强制 system prompt 可能不包含默认规则，本扩展不会覆盖它们。禁用扩展加载的子会话不会得到这条说明。提示不能保证模型永远不填错参数，具体要求仍以各工具接口为准。
