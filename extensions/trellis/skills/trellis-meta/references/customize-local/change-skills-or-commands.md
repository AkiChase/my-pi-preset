# Change Skills Or Commands

`.pi/skills/trellis-*` are Trellis-managed project copies: customized files are preserved and reported as conflicts, and Update resources writes nothing until they are resolved. Product skill changes belong to an intentional package release. Private project skills use other names in Pi-supported project locations. Verify frontmatter, reference closure, filters and collisions. Use real /skill:name or native commands, not fictional aliases.
