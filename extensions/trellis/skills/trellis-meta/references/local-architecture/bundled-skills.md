# Bundled Skills

Trellis skills ship with the package and are deployed by `/trellis-init` (Initialize, Adopt or Update resources) as project copies under `.pi/skills/trellis-*/`, including their supporting references. Pi loads them through native project skill discovery: project trust, skill filters, `--no-skills` and name collisions apply, and the extension injects no skills. After deployment run `/reload` or start a new session; startup never deploys or updates skills. Update resources replaces only files still equal to the last published copy; customized files and unmanaged same-name folders are preserved and reported. `trellis-start` handles both session orientation and resuming the selected task. Paths in supporting references are relative to this skill directory; `.trellis` paths are project-relative. Never continue using an old runtime.
