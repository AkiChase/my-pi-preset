# Hooks And Settings

Execution-project `.pi/settings.json` and personal Pi settings govern resources and trust in their respective scopes. Source-project `.trellis/config.yaml` governs journal settings and explicitly configured task hooks; role path-only dispatch uses native material bounds/diagnostics, not a configurable body-injection budget. Default init has session_auto_commit:false and no hooks. Verified source read authority does not move `.pi` settings to the source root or authorize writes/lifecycle actions. Do not claim configuration is a substitute for Git approval.
