# Context Injection

Pi extension owns session/input/tool events. Runtime and command-carrying bash/monitor receive explicit session keys without mutating host environment. Role dispatch retains four fixed header lines; authority JSON contains only sourceRoot, executionRoot and requirementsFingerprint. The host re-queries native source materials and binding identity before binding the child, retaining full paths/references internally for later path-presence checks. Prompt text alone is not authorization. Roles derive source task/workflow/spec paths from sourceRoot and taskDir, then read PRD/design/implement, workflow and the selected role manifest in order. The manifest is the only complete model-facing reference selection list. Read all selected references within source containment bounds, paginating truncated reads; no injection marker or fingerprint proves actual/full reads, and execution-root `.trellis` is never a fallback.
