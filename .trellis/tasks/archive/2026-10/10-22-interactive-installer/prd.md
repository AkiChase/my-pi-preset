# 交互式安装器

## 目标

将预设的公开安装入口改为无参数的交互式安装流程。用户通过简单的 `curl | sh` 或本地 `./install.sh` 启动安装器，能看见并选择每个同步域及其安全级别，在真实执行前审阅计划并显式确认。

## 已确认事实

- 当前 `install.sh` 是 shell 引导器：检查 Node、curl 和 Pi，远程运行时下载 `pi-preset.json` 与 `scripts/sync.mjs`，再将命令行参数透传给 `sync.mjs`。
- `scripts/sync.mjs` 已拥有 packages、settings、keybindings、files、extensions 五个域的选择、merge/prune 语义、dry-run 计划和执行逻辑；它不依赖 SDK 或第三方 npm 包。
- `curl | sh` 会占用标准输入作为脚本文本；交互输入不能从普通 stdin 读取，必须使用终端设备，且无 TTY 时不能静默执行。
- 用户希望公开安装脚本只提供交互式流程，不要求用户使用 `sh -s --` 传递 `--sync`、`--prune` 等参数。
- 用户要求交互界面美观，并且所有可配置选项可被用户感知。
- 用户已确认无边框多选 TUI 原型，并授权正式实现及清理本次 demo；Esc 判定延迟设为 100ms。

## 范围

### 包含

- 在 Node 中实现安装向导；shell 仅保留引导、环境检查、定位/下载运行材料及启动向导的职责。
- 将原本地检出能力作为可见来源选择；远程安装仍默认远程来源，下载临时目录不可被注册为本地包。
- 向导分两步多选：同步范围默认五项全选，空格切换、`A` 全选/全不选；清理范围仅展示选中的域，默认全不选。同步未选为 skip，清理未选为 merge，清理选中为 prune。
- 以现有同步器的 dry-run 输出作为真实计划预览；摘要同时展示选中和跳过的域。
- 对 prune 选择提供明显的破坏性提示，并要求显式确认后才执行。
- 在 curl 管道场景从终端设备读取交互输入；缺少 TTY 时安全地失败并说明原因。
- 更新 README 中的安装、更新和本地检出说明，使其以交互入口为准。
- 为交互选择、无 TTY 拒绝、计划预览/确认和 shell 下载材料补充自动化测试。

### 不包含

- 修改 `pi-preset.json` 的同步数据或 `scripts/sync.mjs` 的 merge/prune 语义。
- 在安装器中引入第三方终端 UI 库或自动安装 pnpm；本地 Packages 同步经用户确认后可运行 `pnpm install`。
- 支持无人值守、CI 或旧的安装脚本参数透传入口；此任务的产品决定是公开入口仅交互。
- 执行 Pi 安装、`/reload` 或实际个人配置同步作为测试。

## 初步技术方向

- 新增依赖 Node 标准库的安装向导脚本；它将选择转换为内部调用 `sync.mjs` 的参数。
- 用内置 Node 终端能力实现无边框的键盘 TUI：使用 raw mode 和键盘事件处理方向键、模式快捷键、确认、返回及退出；为不支持颜色或 Unicode 的环境设计可读降级。
- 用户已确认 `local/interactive-installer-demo.mjs` 的视觉样式；正式实现后删除该原型，不动其他 local 内容。
- curl 运行时由 shell 额外下载向导脚本；本地检出则直接使用仓库版本。

## 已确定的视觉方向

- 采用无边框的键盘 TUI：先展示来源选择，再选择同步范围与清理范围；方向键移动，空格切换，`A` 全选/全不选，`Enter` 前进，`Esc` 返回，`Q` 退出。在计划审阅页按 `Enter Apply` 直接执行；本地来源且选中 Packages 时，先运行审阅页明确显示的 `pnpm install`，成功后再同步，失败中止。
- 视觉层级依次为：品牌/步骤标题、当前域、完整状态摘要、真实计划预览和底部快捷键提示。禁止使用卡片或字符边框。
- 色彩仅增强含义而非承载含义：merge、skip、prune 具备文字标签和快捷键；禁用色彩后仍可辨识。Unicode 符号按终端能力降级。
- 宽终端保持适当留白；窄终端使用线性文本和相同键盘语义。
