# 优化全量 npm test 的资源占用

## 目标与约束

减少全量测试中的重复初始化、原生查询、文件遍历和无效等待。保留单一 `npm test` 入口、现有发现 globs、文件并发 **8**，不使用显式文件内并发。

- 主会话直接实施、自审；用户要求不启动 agent。
- 每批须批准具体范围；验证后立即本地提交，不 push、不改历史、不安装、不归档。
- 仅改测试及相关说明，不改生产生命周期、初始化/Git/query 算法或 SDK；保留其他任务的并行修改。
- 用户批准删除三组 GC 测试/driver 和未握手忙循环测试，不增加替代专项测试。
- 测试降层不伪造生产算法/哈希：纯规则调用真实函数，真实 Git、路径逃逸、文件保护等关键集成保留代表覆盖。
