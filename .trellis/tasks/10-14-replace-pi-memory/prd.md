# 自研 Pi 持久记忆插件并清理旧 pi-memory

## 目标
提供轻量、可浏览的跨会话项目记忆：保存长期偏好、纠正、非显然的项目约束和外部资源指针，在相关时按需读取，失效时更新或忘记。无后台模型费用、退出总结或会话压缩系统。

## 背景与已确认决策
用户要求移除 pi-memory 及本机旧记忆；替代方案由 npm:pi-claude-memory 改为本仓库自研。Claude Code 的索引/主题文件及保存规则为参考，不复制未经核实的内部实现。用户已确认：只做持久记忆、当前主模型按规则主动保存、按项目存储、不使用刻意的 v2 目录，`/memory` 使用列表→独立详情页。

## 需求
### R1 保存策略
- 四类 user/feedback/project/reference；user 是项目内类型，不是跨项目全局层。
- 用户明确要求记住时立即保存，重要长期偏好/纠正允许主模型主动保存；变化更新原条目，避免重复追加。
- 不保存每日流水、当前任务状态、代码/Git可推导事实、AGENTS.md已有规则或凭证。
- 主模型依据规则保存，不独立后台提取、不每轮AI召回；主动保存不保证捕获所有值得记录的信息。

### R2 存储与发现
- 使用 `<agentDir>/memory/projects/<项目ID>/`，Markdown主题文件和MEMORY.md派生索引。Git子目录/worktree统一身份，非Git按真实cwd隔离。
- 每次独立运行注入有界索引与使用规则，空库也有保存指导；正文按需读，不能once-only或重复叠加。
- 扫描仅读取有界frontmatter元数据，不为生成列表或索引读取全部正文；正文只在read/详情时读取。索引超限明确提示，完整条目仍可通过分页/过滤发现；正文读写、工具结果、扫描和显示工作量有界。
- 创建/更新/删除、人工修改后的刷新和索引修复可用；冲突不静默覆盖，忘记不创建原文恢复备份。

### R3 工具与交互
- 提供memory_read/write/list/forget；write缺正文报错，不隐式删除。
- `/memory` 打开当前项目的全宽列表，↑↓选择、Enter进入独立全宽详情，详情↑↓滚动，返回保留过滤/选中状态。
- 列表展示类型、名称、摘要及项目/状态/数量；支持本地过滤、刷新与明确空态/错误态。详情展示元数据、路径和宿主Markdown正文。
- 详情可编辑及确认删除；保存须通过同一验证/冲突检测，不能绕过工具安全规则。操作不触发模型、不自动把正文加入对话。
- 开关通过菜单操作，关闭后停止注入与写入，但允许查看/导出式复制；已有上下文不宣称被撤销。
- 产品UI与工具文案英文；正文原文保留。窄终端、resize、中文、主题、regular/fullscreen及非TUI均有合理行为。

### R4 安全与生命周期
- 私有数据根，不允许仓库配置重定向到任意路径；安全slug、实际路径验证、拒绝symlink逸出、秘密检查不回显值。
- 无后台提取/待提交模型结果，退出不发起或等待模型/索引flush；关闭面板与旧activation后不能迟到操作。
- 不修改共享Task UI、主编辑器或宿主代码。

### R5 preset与本机迁移
- 移除preset声明和本机个人包配置的pi-memory；不安装pi-claude-memory。
- 仅清理确认属于旧插件的memory根下MEMORY.md、daily等历史数据及独占残留，不递归删除memory根或新projects。
- 不迁移旧记忆，不动Claude Code记忆、Pi会话、Trellis文档、共享qmd或其他用户配置；真实删除前重新列清单核对。
- 处理旧插件仍加载时退出可能重建旧数据的问题，禁止以仅删除目录宣称迁移完成。

## 不做
Session Memory、压缩/树摘要、团队服务、每日日志、向量数据库/qmd、后台fork提取、AI选择器、自动蒸馏/淘汰、日志重放/墓碑恢复、全局个人层、通用任务调度、新Task UI集成。
