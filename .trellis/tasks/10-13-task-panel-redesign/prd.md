# Task Panel 重设计与只读 Agent 概览

## 目标
提高任务浏览可读性，并让主对话直接呈现 agent/workflow 的运行情况与消耗。保留 FleetView 的简洁视觉，不恢复其独立导航系统。

## 已确认需求

### Task Panel
- 列表采用全屏布局，上方 Agents（含 workflow），下方 Processes（shell、monitor）；不加页签。
- 列表与独立全屏详情页在同一 interaction 内切换，不使用左右分栏，也不在列表内展开输出。
- 参考 `../pi-trellis` 的 `/trellis-task-viewer`：使用全终端原生 overlay，打开时覆盖对话与编辑器，关闭后恢复原对话和编辑器焦点/文本；不切换 Pi 整体 fullscreen 模式。
- Enter 进入详情，Esc 从详情返回列表、从列表关闭；返回列表保留选择、滚动位置和分组收起状态。
- 列表与详情正文直接使用 Pi 原生 `ScrollView` 的连续滚动视口及可视滚动条，标题和底栏固定；不沿用手动数组截取或自行绘制滚动条。
- Fullscreen 宿主中支持鼠标滚轮，正文上下边界阻止滚动穿透到底层对话；Regular 保留键盘操作和滚动条，不由插件强行开启终端鼠标捕获。
- 滚轮仅移动视口，不强制移动列表选择；键盘移动选择时确保该项可见，不在每次渲染/定时刷新时拉回旧选择。列表与详情位置独立，返回、刷新、树折叠和 resize 后合理保留或收敛。
- 不引入手动分页，不沿用 PageUp/PageDown 处理或提示；保留方向键、Enter、Esc、树展开/收起及原有选中任务/全局操作。滚动条常驻/按需显示、任务行点击与滚动条拖动尚未确认，不作为本轮已批准实现范围。
- 单行紧凑摘要沿用 FleetView 的留白、圆点及右对齐耗时和 `↓ tokens` 风格。
- 保留 workflow、普通 agent 的真实父子关系，用 `├─ / └─ / │` 树形连接线表现；不把 `▾ / ▸` 放在圆点旁。
- 分组展开只呈现子任务，进入详情才查看输出。折叠父项显示子任务数量，底部根据当前父项状态提示左右展开/收起。
- 同批并行通知批次不是父子关系，不凭空创建父组。
- 延续活跃根组保留已完成子任务、根组终态短暂展示及选中最终详情保留的既有语义。

### 主对话底部概览
- 位于输入框下方、footer 上方，参考原 `src/ui/fleet-list.ts` 的 FleetView 样式，而不是输入框上方的 `agent-widget.ts`。
- 只读展示 agent/workflow 描述、状态、耗时和 `↓ tokens`，限高并明确提示隐藏数量；无可展示任务时隐藏，完成项短暂保留。
- 不恢复原 FleetView 的 `← / ↓` 激活、键盘选择、main 行或独立 conversation/workflow viewer。详情统一从 Task Panel 查看。
- 不恢复 aboveEditor 树状 agent-widget。

### 前台 shell 提示收敛（2026-10-14 补充）
- 移除 process-tasks 在输入框下方独立显示的 `bg-hint`：原始命令/耗时行与 `to run it in the background` 快捷键行均不再显示，不改成默认开启的另一套提示。
- 工具调用保留执行内容展示，共享底栏简洁表达当前等待关系及全局解除等待入口，Task Panel 提供具体进程、耗时、完整命令和日志；不为此把 shell/monitor 加入只读 agent/workflow 概览。
- 保留 `/bg`、可配置 `Ctrl+Shift+B`、前台/后台执行、自动转后台与取消/结果消费语义；快捷键说明必须表达“解除全部当前等待”，不能暗示只操作某条 shell。
- 前台 bash 将 `description` 传递为任务名称，共享任务摘要优先使用可读描述，缺失时回退命令；完整实际命令留在详情，不删除或改写 Trellis 的 session 环境变量注入。
- 本补充覆盖“保留原结构”对独立 `bg-hint` 的约束；其余现有界面结构与导航仍按原范围保留。

### 一致语义与长文本
- 主对话底部与 Task Panel 圆点含义统一：`●` 运行中，`○` 非运行态；文字与语义色区分排队、暂停、完成、失败、停止等。
- 面板选中项采用轻微整行背景，不改变圆点含义。
- 不使用 emoji；保留圆点、箭头和树线等终端字符。
- agent 任务 description 作为主标题，缺失时回退到名称/类型；次级标识不抢占主要描述。
- agent、shell/monitor、workflow 与 progress/阶段的长标题统一保护关键状态和统计；列表/概览截断，详情可查看完整文本。
- Waiting 与 Background 是独立维度，可共存；清晰表达当前等待关系，避免仅凭执行模式判断是否阻塞。
- `Ctrl+Shift+B` 为解除全部当前等待的全局操作，不针对选中任务；操作区域明确区分全局与选中任务操作。

## 验收标准
- 列表上方 Agents、下方 Processes，真实嵌套关系清晰且可收起，无左右分栏、页签或内联输出。
- 全屏列表/详情覆盖整个终端，空白区域不透出底层对话；resize 后按实际行列重算布局，regular/fullscreen 宿主模式均可打开与关闭，恢复编辑器焦点和原文本。
- 原生连续滚动与可视滚动条覆盖长列表和长详情，标题/底栏固定；滚轮不改变选择，键盘选择能进入视口，定时刷新不拉回视口，返回/折叠/内容更新/resize 正确保留或收敛位置。
- Fullscreen 真实终端验证滚轮路由、上下边界不穿透、关闭后主界面恢复；Regular 验证键盘与滚动条且不强行开启鼠标捕获。模拟输入/布局测试不替代真实鼠标验收。
- 列表进入详情及返回保持交互状态；长标题、命令与阶段文案在详情完整可读。
- 两处圆点均按运行情况显示；改变面板选择不改变圆点；选中背景可辨识。
- 原 FleetView 风格概览在输入框下方展示，右侧耗时/tokens 不因长标题消失；不拦截旧 FleetView 导航键。
- 概览/列表限高、窄屏、ANSI 宽度、中文长文本与深层树形分组有回归覆盖，统计不重复计算父子消耗。
- 后台无等待、后台取结果等待、前台启动等待均有正确展示；全局解除等待保留既有执行与取消契约。
- 超过两秒的前台 shell 不再创建独立 `bg-hint`；多 shell/agent/retrieval 同时等待时只由共享 UI 表达等待和全局解除入口，完成/detach/reset/shutdown 无遗留提示。
- 前台 shell 的可读 description 在任务摘要生效，详情保留完整执行命令（包括 Trellis 环境前缀）；无 description 时安全回退，执行参数不因展示处理改变。
- shell/monitor/agent/workflow 现有执行、结果消费和终态保留契约不回归。

## 非目标
- 不重写执行后端、取消/调度/通知机制。
- 不恢复独立 backend UI 或多个详情查看器。
- 不默认增加尚未暴露的上下文百分比/compaction 等统计。

## 统一长标题范围
用户选择一起统一：新 Task Panel、底部概览、活跃 workflow progress 卡片、主对话 Agent 调用/完成摘要、/agents 对话/workflow 专用查看器，以及 shell/monitor/Beautify bash 渲染的可见标题与统计。统一的是语义映射、文本安全处理与宽度预算，不强制所有界面采用相同布局，不重写旧查看器导航或执行/通知逻辑。用户已认可具体适配方案并完成审阅。

## 授权与规划状态
用户批准设计方向、全部列出的长标题呈现路径，并明确完成方案审阅。无阻塞性产品问题；后续仅完成子任务拆分、上下文与工作区技术门禁，再进入实施。
采用父任务整体验收，子任务一交付共享展示规则及现有界面适配，子任务二依赖其共享接口后交付新面板与只读概览；子任务 artifact 必须写明依赖。
