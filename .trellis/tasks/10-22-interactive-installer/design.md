# 交互式安装器设计

## 决策与授权

用户已确认无边框键盘 TUI 原型，并于本轮明确授权开始正式实现及删除本次 demo。保留 100ms Esc 序列判定延迟。仅删除 `local/interactive-installer-demo.mjs`，不清理其他 local 内容。

## 结构

- `install.sh`：无参数公开入口；拒绝旧参数，验证交互终端与依赖，选择本地文件或下载 manifest、sync.mjs、install.mjs；在下载前注册临时目录清理。将 Node 标准流连接 `/dev/tty`，不从管道脚本文本读按键。
- `scripts/install.mjs`：只依赖 Node 标准库。拥有键盘状态机、无边框渲染、真实预览子进程、确认和执行。允许内部 `--manifest` 定位下载清单；不将同步参数作为公开安装入口。
- `scripts/sync.mjs`：保留当前同步语义与内部参数接口，不复制计划生成或执行算法。

## 流程

1. 来源：远程预设默认选中；本地检出在可用时可选。下载方式展示本地选项不可用，不允许临时目录被注册为 dev 来源。此步骤使原 `--dev` 能力可见。
2. 同步：五域多选，默认全选；空格切换、A 全选/全不选、方向键移动。
3. 清理：仅列选中的域，默认全不选；清理选择为 prune，其余 merge。提示 merge 也可能执行清单声明的冲突移除与 null 删除。
4. 预览：运行实际 `sync.mjs --dry-run`，成功后显示所有域模式及真实输出；支持滚动长计划。非零退出或预览超限不能进入确认。
5. 执行确认：用户已批准审阅页 Enter 直接执行，移除 APPLY 输入页。执行与预览一致的来源/域参数（去掉 dry-run）；返回修改选择使旧预览失效。
6. 本地依赖：仅本地来源且选中 Packages 时，审阅页显示先运行 `pnpm install`；确认后在本地检出执行，成功才启动 Pi 同步，失败中止；缺少 pnpm 报错，不安装 pnpm。远程或只选配置域不运行依赖安装。
7. 执行：恢复普通终端以完整显示同步器实时进度；等待真实退出，不因启动成功而宣告完成。失败返回非零码，成功提示 reload。

## 安全与生命周期

没有 TTY 时拒绝，不能静默按默认值执行。输入按键在执行中不触发新流程。退出与信号取消预览子进程，保留至真实 exit，并在必要时升级 SIGKILL；终端 raw mode、alternate screen、光标与事件监听器都有幂等清理。预览捕获设置字节上限和总超时；外部控制字符过滤后才进入 TUI。执行直接继承终端，输出不截断。

预览与执行之间配置可能被外部更改；执行沿用现有同步器的新鲜读取/锁语义，保证选择一致但不承诺快照冻结。此任务不更改同步器合同。

## 视觉

沿用用户认可的留白、指针预留列、多选符号、蓝绿色标题、危险文字提示；无字符边框。禁色/Unicode 降级，按终端宽高限制显示并支持预览滚动。用户界面英文，用户文档中文。

## 验证

纯状态/渲染测试、fake sync 子进程测试、fake curl shell 引导测试、真实 PTY 离线集成验证。全部测试使用临时目录与 fake Pi，不读写个人配置或联网安装。独立 reviewer 检查删除/确认/子进程/入口兼容性边界。
